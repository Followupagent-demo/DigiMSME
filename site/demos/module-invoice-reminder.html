⚡ Real Workflow, Not a Mockup

The story above, as the actual automation that runs it

Built in n8n, the open-source workflow engine. Tap play below and watch it run end to end — this is what "Invoice + Payment Reminders" actually is, not a diagram standing in for one.

⚡ New Invoice / Booking Created
⏱ Wait 7 Days
🔍 Check Payment Status
🔀 Still Unpaid? ↳ otherwise: Paid — Stop (Day 7)
💬 WhatsApp: Gentle Reminder (Day 7)
⏱ Wait 7 More Days
🔍 Check Payment Status (Day 14)
🔀 Still Unpaid? (Day 14) ↳ otherwise: Paid — Stop (Day 14)
💬 WhatsApp: Firm Reminder (Day 14)
⏱ Wait 16 More Days
🔍 Check Payment Status (Day 30)
🔀 Still Unpaid? (Day 30) ↳ otherwise: Paid — Stop (Day 30)
💬 WhatsApp: Final Notice (Day 30)
🔔 Alert Owner
